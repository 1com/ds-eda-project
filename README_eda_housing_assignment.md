# Housing EDA Assignment

Exploratory data analysis on housing sales data, covering data cleaning, neighborhood segmentation, and hypothesis testing around sale price behavior.

## Project Structure


| Notebook | Description |
|---|---|
| [01_cleanfinal.ipynb](01_cleanfinal.ipynb) | Data cleaning: handles missing values, fixes data types, removes/treats outliers, and prepares the raw dataset for analysis. Outputs the cleaned dataset used by all downstream notebooks. |
| [02_middle_class_neighbourhoods.ipynb](02_middle_class_neighbourhoods.ipynb) | Identifies middle-class neighborhoods within the dataset, using this segmentation as the basis for later hypothesis testing. |
| [03_hypothesis_1.ipynb](03_hypothesis_1.ipynb) | **Hypothesis 1:** Sale price varies throughout the year. Analyzes seasonal/monthly trends in sale price. |
| [04_hypothesis_2.ipynb](04_hypothesis_2.ipynb) | **Hypothesis 2:** Profit maximization analysis — examines factors (e.g. condition, renovation, grade) associated with maximizing sale profit. |
